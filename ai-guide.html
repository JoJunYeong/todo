직접 다룰 수 있게

Daynote의 설정 → AI 연결에서 연결 파일을 한 번 발급하세요. AI는 브라우저 로그인 없이 허용된 데이터에 접근합니다. 조회 전용과 조회·저장 권한을 따로 지정하고 언제든 폐기할 수 있습니다.

실제 API는 Firebase HTTPS 서버에서 처리합니다. 이 GitHub Pages 페이지는 연결 안내, 클라이언트, API 설명서를 제공합니다. 유료 서버나 Daynote 비밀번호 공유는 필요하지 않습니다.

1. 연결 파일 받기

  1. Daynote에 로그인하고 계정 설정의 AI 연결을 엽니다.
  2. AI 이름, 권한, 유효 기간을 선택하고 새 AI 연결 만들기를 누릅니다.
  3. 연결 파일 내려받기로 JSON을 보관합니다. AI 도구의 비밀 저장소나 본인만 읽을 수 있는 파일로 저장하세요. Git·공유 대화·공개 URL에 넣지 마세요.

연결 파일은 발급 직후에만 내려받을 수 있습니다. 잃어버리면 기존 연결을 폐기하고 새 연결을 만드세요. 한 AI의 연결을 폐기해도 본인 로그인과 다른 AI 연결은 유지됩니다.

2. 사용할 AI 도구에 연결하기

HTTP 요청, 셸 실행, MCP 중 하나를 지원하는 AI에서 사용할 수 있습니다. 텍스트 대화만 가능한 AI는 외부 저장을 실행할 수 없습니다.

AI 클라이언트 내려받기HTTP API 설명서

셸 실행이 가능한 AI

Node.js 22 이상이 필요합니다. 연결 파일을 ~/.config/daynote/credentials.json에 두거나 DAYNOTE_AI_CONFIG 환경변수로 경로를 지정하세요.

node daynote-ai.mjs call < request.json

request.json 예시:
{"operation":"listTasks","query":"보드 시험"}

MCP를 지원하는 AI

MCP는 AI 도구에 외부 기능을 연결하는 방식입니다. 아래 예시의 두 경로를 실제 파일 위치로 바꾸어 AI 앱의 MCP 설정에 넣으세요.

{
  "mcpServers": {
    "daynote": {
      "command": "node",
      "args": ["/실제/경로/daynote-ai.mjs", "mcp"],
      "env": {"DAYNOTE_AI_CONFIG": "/비공개/경로/credentials.json"}
    }
  }
}

HTTP 요청이 가능한 AI

OpenAPI 설명서와 연결 파일을 사용합니다. 먼저 Firebase 토큰 갱신 API로 AI 전용 ID 토큰을 얻고, Authorization: Bearer ID_TOKEN으로 Firestore REST API를 호출합니다. 토큰을 URL이나 프롬프트에 넣지 마세요. 수정은 서버의 updateTime을 조건으로 사용합니다. 상세한 중복 방지 요청 형식은 API 개발 안내에 있습니다.

모든 저장은 중복 방지 기록과 함께 처리하고 저장된 내용을 서버에서 다시 읽습니다. 다른 기기의 변경이 있으면 최신 내용을 다시 확인하게 합니다. 반복 일정은 저장된 원본을 조회하며 특정 발생일 생성·반복 규칙 변경·영구 삭제는 지원하지 않습니다. 이 연결은 일정과 메모를 저장하며 실제 보드 시험이나 다른 외부 작업을 실행하지 않습니다.

연결 중지

설정 → AI 연결 → 해당 연결의 폐기를 누르면 그 AI의 다음 조회와 저장 요청이 거부됩니다. 유효 기간이 끝나거나 본인 계정이 사용 중지돼도 차단됩니다. AI는 계정 설정, 사용자 관리, 관리자 권한, 가져오기 기록과 메모 이미지 원본에 접근할 수 없습니다.

기술 근거: Firestore REST 인증 · Firebase 토큰 갱신
