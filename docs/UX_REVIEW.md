# 일정표 가독성 검토

2026-10-21. 기존 게시 화면과 수정한 배포용 미리보기를 같은 계정·주간·화면 크기로 비교했다. 개인 일정 제목, 메모와 화면 캡처는 공개 저장소에 포함하지 않는다.

## 발견한 문제와 적용

- 기본 사이드바와 큰 소개 영역이 일정표의 공간을 차지했다. 모든 화면에서 사이드바를 기본 접힘으로 시작하고 상단 메뉴 버튼으로 열고 닫는다. 큰 제목·소개·진행률 카드는 작은 제목과 완료 수로 바꿨다.
- 할 일 글자가 PC 12px, 휴대폰 13px로 작았다. PC·태블릿은 14px, 휴대폰은 15px로 늘리고 줄 간격과 체크박스 간격을 조정했다.
- 완료된 카드 전체에 투명도 0.6이 적용돼 글자가 흐렸다. 투명도는 없애고 취소선과 진한 보조 색으로 완료 상태를 구분한다. 원래 일정 색은 유지한다.
- 좁은 공간에 일주일 7열을 유지하면 긴 제목을 읽기 어렵다. 일정표 공간이 1150px 이하일 때 4열, 휴대폰에서는 선택한 하루를 표시한다. 사이드바를 열어 공간이 줄어들 때도 열 수가 조정된다.
- 모바일 메뉴는 배경 스크롤·키보드 포커스를 제한한다. Esc·닫기·바깥 클릭으로 접고 버튼으로 포커스를 돌려준다. 넓은 화면으로 전환하면 제한을 해제한다.
- 검색 단축키는 메뉴를 닫고 검색창으로 이동한다. 상세 창 안에서는 단축키가 포커스를 빼앗지 않는다. 상세 창에서 Esc를 눌러도 기존 검색어와 결과가 유지되도록 고쳤다.

## 비교 결과

위치는 화면 맨 위에서 첫 할 일 제목까지의 거리이며, 같은 주간의 기존 자료로 측정했다.

| 화면 크기 | 기존 첫 할 일 | 수정 후 | 수정 후 글자 |
| --- | ---: | ---: | ---: |
| PC 1440×900 | 407px | 191px | 14px |
| 태블릿 1024×768 | 416px | 191px | 14px |
| 휴대폰 390×844 | 482px | 253px | 15px |

실제 색과 투명도를 반영한 할 일 제목의 대비는 최저 1.92:1에서 5.10:1로 높아졌다. 18조합 모두 4.5:1 이상이다. 이 검사는 할 일 제목 색 조합에 대한 결과이며 전체 WCAG 적합성 인증은 아니다.

## 확인 범위

- 배포용 빌드에서 폭 320·390·768·1024·1440px의 화면을 직접 확인했다. 가로 넘침 없이 제목과 체크박스를 표시한다.
- 메뉴 기본 접힘·반복 열기와 닫기·바깥 클릭·Esc·Tab 순환·검색 단축키·모바일에서 넓은 화면으로 전환·새로고침 후 기본 접힘을 확인했다.
- 검색 결과와 메모 열람, 상세 창 닫기 후 검색 유지, 설정 열기, 휴대폰 요일 선택과 이전·다음 주 이동을 확인했다. 검토 과정에서 기존 할 일 내용을 수정하지 않았다.
- 날짜·검색·반복·백업 검사 22개와 배포 빌드가 통과했다. 인증·DB 접근 규칙·이관 로직은 이번 변경 범위에 포함하지 않았다.
- 초기 화면 JavaScript 압축 크기는 약 97.6kB로 유지된다. 이번 변경은 메뉴·키보드 동작과 화면 스타일이 중심이며 새 실행 의존성을 추가하지 않았다.
