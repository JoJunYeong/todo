# 검색 결과에서 찾은 위치 열기

검색 결과는 메모 첫 부분 대신 일치하는 문장 주변을 보여 준다. 제목과 발췌문의 검색어를 강조하고, 결과의 문장을 눌러도 상세창이 열린다. 다른 캘린더의 날짜 없는 항목도 실제 캘린더와 목록 이름을 표시한다.

상세창은 메모, 제목 또는 일치하는 체크리스트 항목이 보이도록 이동하고 약 2초간 강조한다. 긴 제목과 체크리스트 입력란 안의 가려진 글자도 표시한다. 일반 일정표에서 열 때는 위에서 시작한다. 동작 줄이기 설정에서는 깜박임 없이 잠깐 강조한다.

강조 표시는 편집 영역 밖에 잠깐 표시한다. 메모 HTML, 커서와 실행 취소 기록을 바꾸지 않으며 입력을 시작하면 사라진다. 스크롤 이벤트에서 검색하거나 메모를 다시 그리지 않는다. DB에 검색 위치나 강조 태그를 저장하지 않는다.

## 확인한 범위

- 긴 HTML 목록의 뒤쪽 문장, 인라인 굵은 글씨를 가로지르는 문구, 마크다운 목록, 체크리스트와 긴 제목을 확인했다.
- 한글 초성, 전각 영문, 공백과 유니코드 정규화, 정규식처럼 생긴 일반 문자열을 검사한다. 검색 결과는 HTML로 삽입하지 않고 일반 글자로 표시한다.
- 브라우저에서 폭 320·390·768·1024·1440px의 검색 결과와 상세창 이동을 확인했다. 검정 카드의 제목 대비와 좁은 화면의 발췌문 높이도 조정했다.
- 별도 가상 데이터로 열람 시 쓰기 없음, 편집 후 저장, 변경 없이 저장 시 메모 원문 보존, 강조 표시 제거, 일반 카드 재열기와 스크롤을 확인했다. 가상 데이터 테스트는 실제 Firebase에 연결하지 않는다.
- `npm test` 55개와 배포 빌드를 실행한다. 기존 인증·DB 접근 규칙·자동 이월·완료 순서 로직은 변경하지 않는다.

운영 게시는 별도 승인 절차를 거치며, 이 문서의 구현 검증과 실제 게시 상태는 구분한다.
